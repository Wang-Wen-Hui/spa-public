# 科研文献汇报内容规划

适用于文献汇报。内容以当前用户的目标和已核实的论文证据为准。

## 主线与页面契约

默认骨架为背景 → 主体证据 → 讨论 → 结尾。侧栏仅列精简、具体的大章节；背景用1.1、1.2等编号，主体的2.1、2.2等对应论文Figure 1、Figure 2，每张Figure一个总标题。背景须回读本篇完整前言，沿既有工作、局限与研究需求展开。不生成备份或附录页。

| 页的任务 | 观众需要看到 | 备课时必须查清 |
| --- | --- | --- |
| 封面/导航 | 准确论文题名、作者/期刊/年份/版本、汇报人日期；实际章节 | 清除旧论文作者、DOI、页脚、目录、备注和母版中的残留 |
| 作者与团队 | 通讯作者照片、姓名、论文相关的实验室方向；相关导师或知名科学家亲属合计 1–2 人即可 | 论文署名确认通讯身份；官方页面/学位材料确认导师与亲属关系、肖像来源；区分发文时机构与当前机构 |
| 概念背景 | 听懂后文所需的概念、术语和示意关系 | 首次出现的缩写全称、中文和“在此实验里做什么”；同一缩写是否另有含义 |
| 背景证据图 | 对象、方法/设计、处理与比较、读出、已知结论和剩余问题 | 即使来自综述，也要读图注；必要时追到原始实验，不能只讲意义 |
| 研究问题 | 现有办法缺什么、本文针对哪个可检验问题、作者策略 | 用后续关键证据实际能检验的问题，避免拔高成解决整个领域 |
| 原理/技术设计 | 输入→关键步骤→输出；每个元件/参数的目的 | “为什么这一步能测到目标量”、关键假设、对照能排除什么；公式变量、单位和适用条件 |
| 实验结果 | 忠实翻译的主图总标题、准确的图组短标签、图/Panel、设计、关键对照、坐标/读出、必要统计与限定 | 样本/处理/时间/n、重复类型、误差线、检验；直接观察与解释分开 |
| 算法/模拟 | 节点/边/阈值等规则、可手算例；真值、改变的参数、基准方法、评价指标 | 示意图不等于性能证据；模拟、真实数据和跨场景验证分开 |
| 机制/讨论 | 哪些发现已支持、哪些是作者模型、哪些替代解释未排除、适用边界 | 模型图真实来源；避免把相关性说成因果、不可检测说成不存在 |
| 应用 | 与本研究有关的具体问题及依据 | 适用条件、工具版本；实操命令需当前文档核查，历史论文参数不是通用建议 |
| 结束 | 回答开头问题的一句认识、致谢 | 不在结束页突然引入无证据的新结论 |

作者关系没有可靠来源就不凑数、不凭姓氏或传闻推断；记录未确认并告知用户。不要让人物简介挤占科学主线。

## Figure 的组织

先选图，再写背景。完整阅读 Introduction，将每个背景论点对应到原文段落和被引文献；对承担主线的论点追读相关文献的具体图和图注。记录候选 Figure/Panel、它展示的事实、与本文问题的关系、采用/舍弃理由。不能用泛泛的领域介绍替代本文前言，也不能只列参考文献而没有找到实际图。必要的引用文献原图可用于背景，补充图仍执行备注文字政策。

主图标题默认翻译原图图题，优先自然、准确的名词短语。保留原题对象与方法，结果标题的强度不得超过原题与数据。仅在原题过长时做可追溯的精简；不为叙事衔接额外发明“揭示…密码”“构建…桥梁”等标题。大纲同时记录英文原题和中文标题，方便核对。

大纲应附实际图形的规划：源页码、裁切边界、宽高比、保留的 Panel/图例/轴/比例尺，以及在页面中的预计尺寸。先按真实形状试排；一张竖图不能只因模板习惯被塞进宽扁框。多个 Panel 可以在保留标号与科学关系的前提下重排，不能改动图中数据或剥离对照。

每个候选 Panel 记录：科学问题、样本/干预/对照、方法与读出、观察、限制、图注与 Methods 定位、是否需要补充验证。标题应与测量变量一致：例如受体阳性比例不能写成棘寿命；相关系数不能当作准确率。

每张主图默认用1页，必要时最多2页。先尝试保留完整Figure或整组相关Panel，压缩正文、扩大图区、优化排列；只有关键图像、对照、坐标或统计仍无法读清时才拆为2页，并在大纲记录具体原因。多个问题、多个实验步骤或多个Panel本身不是拆页理由。对照与对应结果放在一起。

同一Figure跨两页时，章节编号和总标题完全相同；不另起Panel级页标题，不添加2.1.1等子层级。“第1/2页”如有需要可作次要进度提示，不改总标题。图框短标签只帮助识别图组，不另造一套小节目录。

少字多图，正文保留少量关键信息和必要读图提示。首次出现的图类型必须讲清怎么获得、各视觉元素表示什么；详细过程、完整术语和算法推导进入本页备注，图中已有清楚图例的内容不在正文重复铺陈。讲解充分不等于增加正文文字或增加幻灯片。

计数覆盖同一主图在汇报中的所有展示页；不通过增加“背景概览”“方法专页”“验证专页”或改名章节绕过2页上限。背景可用简短文字交代主线，不预先重复主图。总页数按主图实际1–2页加必要背景、讨论与结尾推导，不预设冗长目标页数。

视觉沿用选定主题：虚线圆角图框、顶部中央深色白字结论标签、关系箭头、白底黑字具体说明、浅灰底深色字提炼，以及白底强调色关键词。颜色承载层级，不要一页混用两套主题。

## 材料与版本

读实际 PDF 页尾，不能仅按文件名判断 main/supplement。合并件中重复的补充材料只登记一次科学证据；记录其在不同文件里的页码映射。区分预印本与正式版；不混用图号、数据和发表信息。

在项目中维护 `materials-status.md`：材料名称/版本、已拿到的页/图、缺失项、受影响的页面或结论、处理方式。原文引用“详见 SI/补充统计/原始图”时，必须跟进对应文件；Extended Data 不自动代表全部 Supplementary Information。

对理解设计或关键对照必需的引用文献，应获取原文/图注；不必为所有背景句子无限追溯。获取失败或仍不可核实时，向用户具体报告缺失；不要用示意图冒充原图、不用模型记忆补数值。非关键内容可有理由省略，关键内容需解决后才写成核实结论。

## 大纲审核前

给出每页的任务、结论/问题、原图/Panel、方法解释需求、术语、与前后页的关系及材料缺口。检查讨论和结束是否齐全，背景是否真正引出主体。页数与时长随信息复杂度调整；这份契约不是每页都填同样数量方框的模板。

## 默认展示范围（可按用户要求调整）

作者背景页无内容框，展示真实肖像和姓名；机构、方向、导师和一两位相关科学家的具体关系放备注。补充材料全量阅读，附图不进入 PPT，必要实验设计/原理/对照以文字放相关页备注。图清单区分“主图展示”“备注文字采用”“已读未采用”。
