# 汇报者备注

备注帮助找回名词和理解实验，不是口播稿或审核清单。依据正文、图注、Methods 与已读补充材料写具体解释。

- 术语：全称、中文、在本实验中的作用。
- 读图：实际 Panel、颜色/通道、方向、轴与单位、符号、比较组、比例尺，以及图像或统计量怎么形成。
- 方法/实验设计：实际材料、标记、处理、成像、对照与关键参数。
- 原理：算法输入、变量、关键步骤和输出，信号为什么支持这一读出。
- 人物背景：发文时机构、方向、核实的导师/相关科学家与具体关系；相关人物一两位即可。

用肯定、具体的描述，不写“不要/别/不能这样讲”等禁令；无边界栏目、图索引、出处、证据 ID、制作说明或强制衔接。必要科学适用范围可在讨论正文表达，详细疑点和来源保留 evidence.md / materials-status.md。

每张主图仅用1–2页，正文少字多图。首次出现的图类型在正文保留最必要的读图提示，完整获取方法、逐元素说明和算法原理写在备注，供讲解与回忆。合并Panel页时合并对应备注、删除重复解释，按读图顺序整理，不能随页数压缩丢掉必要方法，也不逐页复制整图的全部备注。附图不入PPT，也无备份页；必要信息以文字放进相关主图页备注。

## 数据契约与复核

顶层 `notes_mode: "cues"`。`speaker_cues` 支持 `term`、`readout`、`design`、`method`、`principle`、`background`；`order` 兼容既有读图顺序。每条绑定本页 evidence ID，但 ID 不写入备注。旧 `caution` 仅兼容历史数据，生成器不输出，新增计划不使用。

证据全文、来源和核查信息保存 evidence.md。程序检查引用归属与覆盖，宿主 Agent 核查实际科学内容、图/术语/方法对应、长段重复和禁令句；不自动截断长备注。
